# UI Build Directory

This directory contains the **production build** of the React frontend application.

## ⚠️ Important

- **DO NOT edit files in this directory manually**
- **DO commit this directory to version control** (it's needed for deployment)
- This directory is automatically generated by the build process

## Building the Frontend

To rebuild the frontend application:

```bash
cd frontend
npm install
npm run build
```

This will:
1. Compile the React application
2. Bundle all assets
3. Output the production build to `zoomforeducationv1/ui/`
4. Overwrite all files in this directory

## Files in this Directory

- `index.html` - Entry point HTML (not used, iframe.php serves as entry)
- `assets/` - JavaScript, CSS, and other bundled assets
  - `index.js` - Main application bundle
  - `*.js` - Additional chunks and dependencies
- `vite.svg` - Vite logo (favicon)

## Deployment

When deploying the Moodle plugin:
1. Ensure you've run `npm run build` in the `frontend/` directory
2. Commit all files in this directory
3. Deploy the entire `zoomforeducationv1/` directory to Moodle's `mod/` folder

## Troubleshooting

**Problem:** Application shows blank screen or "Failed to load module"
**Solution:** Run `npm run build` in the frontend directory to regenerate this folder

**Problem:** Changes to React code don't appear
**Solution:** You need to rebuild. Run `npm run build` after making changes to frontend code

**Problem:** Build fails
**Solution:** 
1. Delete `node_modules` in frontend directory
2. Run `npm install`
3. Run `npm run build`
